# 障碍物全局坐标数据流

## 流程图

```
MID360 雷达
    │
    ▼
pc_detector (radar_detect包)
    │  输出: radar_interface::msg::TargetArray
    │  坐标系: livox_frame (world_frame默认="lidar")
    │  话题: /pc_detector/targets
    ▼
rel_yaw_dist_node (radar_detect包)
    │  把 xyz 转成极坐标 (dist, yaw)
    │  yaw = atan2(y, x), dist = hypot(x, y)
    │  输出: Float32MultiArray [dist, yaw, dist, yaw, ...]
    │  话题: /pc_detector/rel_yaw_dist
    ▼
red.cpp :: relYawDistCallback()
    │  遍历数组, 取 dist 最小的障碍物
    │  存入 obs_dist_, obs_yaw_, has_obs_
    ▼
red.cpp :: sendLoop()
    │  1. obs_dist_/obs_yaw_ → livox_frame 下的 xyz
    │     x = obs_dist_ * cos(obs_yaw_)
    │     y = obs_dist_ * sin(obs_yaw_)
    │
    │  2. TF 变换 livox_frame → map
    │     (同 chase 包的方法)
    │
    │  3. 填入 SerialOutFrame.obstacle_x/y
    │
    │  4. append_CRC16_check_sum → 串口发送
    ▼
STM32 电控 (35字节帧)
```

## 帧布局 (35字节)

| 偏移 | 类型   | 字段          | 说明 |
|------|--------|---------------|------|
| 0    | u8     | header        | 0x5A |
| 1    | float  | linear_x      | 底盘速度 |
| 5    | float  | linear_y      | |
| 9    | float  | angular_z     | |
| 13   | float  | yaw           | gimbal yaw |
| 17   | float  | dist          | 目标距离 |
| 21   | bool   | if_turn       | |
| 22   | u16    | region        | 区域号 |
| 24   | u8     | attack_target | |
| **25** | **float** | **obstacle_x** | **障碍物全局X** |
| **29** | **float** | **obstacle_y** | **障碍物全局Y** |
| 33   | u16    | crc           | CRC-16 |

## 测试

```bash
# 终端1: 启动 red 节点
ros2 launch serial_communication red.launch.py

# 终端2: 发布假数据模拟障碍物
python3 test/test_obstacle_flow.py

# 终端3: 查看 red 节点日志
ros2 topic echo /pc_detector/rel_yaw_dist
```

## 无障碍物时

- rel_yaw_dist 发空数组 → has_obs_ = false → obstacle_x/y = -1.0f
